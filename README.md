# Ökǒmomorîrěmnant — portfolio

Discord servers, Telegram bots, web scrapers and websites. Static site in four languages (RU · EN · PT · JA).

- `index.html` — the portfolio page
- `i18n.js` — all copy: UI strings, services, cases, FAQ, reviews
- `work/vitrine/` — demo: concept storefront with a particle field and live shaders
- `work/paper-vs-skills/` — demo: 3D scrollytelling on Three.js
- `assets/` — case screenshots

No build step. Open `index.html` through any static server, or publish with GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

Language can be forced with `?lang=ru|en|pt|ja`.
